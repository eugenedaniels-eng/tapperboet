# TapperBoet 🍺🇿🇦

**▶ Play it now: https://eugenedaniels-eng.github.io/tapperboet/**

*(TapperBoet — pixel-art remake of the 1983 arcade classic **Tapper**, with a proper
South African twist. No image files, no build step, no dependencies: every sprite,
font glyph and sound is generated by code.)*

## Naby jou nabyste kroeg — how to run

Just open `index.html` in any modern browser. That's it. Double-click it.

```
tapperboet/
├── index.html        ← open this
├── css/style.css     ← CRT frame + pixelated scaling
├── js/
│   ├── sprites.js    ← ALL pixel art as code (palette + string grids) + 5×5 font
│   ├── audio.js      ← WebAudio synth SFX + chiptune sequencer
│   ├── input.js      ← keyboard handling
│   ├── levels.js     ← venues, customer types, drink pools, waves, load shedding
│   ├── entities.js   ← bartender, customers, mugs, particles
│   ├── ui.js         ← HUD, venue backgrounds, screens, braai bonus
│   └── main.js       ← game state machine + rules
└── dev/
    ├── preview.html  ← sprite sheet viewer (art QA)
    └── harness.js    ← headless bot smoke test: `node dev/harness.js`
```

## How to play

You're the barman. Four bars, thirsty oke's walking in from the left.

- **← → / A D** — slide along a bar
- **↑ ↓ / W S** — change bars (only at the right end, by the taps)
- **1–4** — pick the drink (see the icon above your head + HUD)
- **SPACE** — pour a pint of the selected drink; it auto-slides down the bar
- **V** — **VUVUZELA**: stuns every customer for a moment (long cooldown, properly irritating)
- **B** — **BILTONG TOSS**: lobs a stick of biltong to the angriest walker; they calm down and walk back (3 per level)
- **E** — whack the **generator** during load shedding (stand on the bottom bar, right end)
- **P** — pause · **M** — mute

### The rules of the kroeg

- A customer shows their order in a speech bubble. Pour **that** drink — a wrong pint
  sails right past them (you can serve the okes behind them, but don't waste stock).
- Catch the **empty mugs** they slide back, or they fall off your end. EISH.
- Unclaimed pints slide off the customers' end and shatter — also EISH.
- Run out of patience and they **march** toward you. If one reaches you, that's a life.
- Lose all 3 lives (mugs) and it's *EISH, BOET* — game over. Extra life every R500.

### The South African bits

- **Venues**: Die Shebeen (Jozi) → Bok Stadium Bar (Pretoria) → Durbs Beach Bar (Durban)
  → Klopse Kroeg (Kaapstad), then loop with more pressure.
- **Drinks**: Castle, Klipdrift, Savanna, Black Label — each venue stocks a subset.
- **Load shedding**: the HUD shows the schedule ("LOADSHED IN 12S"). When the lights die,
  pours slow down, patience drains faster, and the generator on the bottom bar starts
  flashing — run down and press **E** (+R25 bonus, you hero).
- **Braai bonus round** after every venue: flip the boerewors when the marker hits the
  green zone. Perfek = R50, lekker = R25, burnt = shame.
- **Cast**: Bokke (thirsty), Taxi Man (fast and furious), Toeris (slow, rich, wears a hat),
  Klopse (dances while waiting), Oupa (patient, walks with a stick).

## Dev notes

- **Zero assets.** Sprites are arrays of strings mapped through a 16-colour palette and
  baked (with outlines) onto offscreen canvases at boot. Text uses a hand-made 5×5 font.
  All audio is synthesized (square/triangle/saw + noise) — the vuvuzela is two detuned
  sawtooths, as nature intended.
- **Balance data** lives in `js/levels.js` (venues, waves, patience, load-shedding cuts).
- **Testing**: `node dev/harness.js` runs the whole game headless — a chaos monkey
  hammering random keys, then an auto-playing bot that must survive level 1, plus
  scripted checks for the braai, victory, loop restart, pause and game over.
- **Art QA**: open `dev/preview.html` to see every sprite and font glyph blown up.
